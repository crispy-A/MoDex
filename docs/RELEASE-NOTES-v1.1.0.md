# MoDex v1.1.0

保存可靠性版本：把写盘收归主进程，加入内容哈希版本校验、原子写与外部变更感知。

## 新增

- **可靠保存**：sha256 版本令牌 + 每路径串行队列 + 临时文件 `fsync` + rename 前迟到校验。
  外部修改/删除不会静默覆盖；冲突时可选「覆盖保存 / 重新加载 / 另存为 / 取消」，
  文件被删除时可选「重新创建 / 另存为 / 取消」。
- **外部变更感知**：当前文件被其他程序修改时，干净文档自动重载；脏文档显示非阻塞提示条
  （重新加载 / 保留我的修改 / 另存为），文件被删除时提供重新创建入口。
- **BOM 保留**：读取记录 UTF-8 BOM，保存按原编码写回；新文件默认无 BOM。
- **AI 生成参数**：上下文窗口 / 最大输出 token / 思考等级可在 AI 设置中配置
  （默认 128K / 8K / high，上限 1M / 384K）。

## 改进

- 回收站不可用时中止删除并保留文件，不再静默回退为永久删除。
- 并发打开文件只允许最后一次请求落地；`ai-store` 并发保存共享加载 + 串行写盘。
- IPC 来源校验、`app://` 协议、导航策略抽成可注入模块并补 9 项安全单测；
  `window.__qm` 调试钩子只在 e2e/自动保存验收模式暴露。
- 预览按需渲染与去重、文件树仅在根变化时持久化、流式回答按长度自适应降频。
- 新增 `npm run check` 语法门禁、Windows CI、MIT LICENSE，修正文档与实现漂移。

## 下载

- `MoDex-1.1.0-setup.exe`：Windows 安装包（Inno Setup，按用户安装、无需管理员、中文向导），98.4 MB。
- `MoDex-1.1.0-win32-x64-portable.zip`：绿色便携版，135.8 MB，解压后运行 `MoDex.exe`。
- 两个 `.sha256` 文件用于校验下载内容。

## 说明

- 安装包未做代码签名，首次运行 SmartScreen 可能提示「未知发布者」。
- 升级使用固定 AppId 覆盖安装，保留 `%APPDATA%\MoDex`（设置、AI 会话、加密后的 API Key）。
- 系统要求：Windows 10/11 x64；AI 功能需自备 DeepSeek API Key，未配置时应用完全离线可用。
